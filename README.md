
# Plataforma de Gestión de Inventario

Proyecto académico de Desarrollo Web Integral para organizar y administrar el inventario de una tienda de blancos y confecciones.

## Objetivo

Desarrollar una aplicación web que permita consultar y gestionar productos de manera organizada.

## Tecnologías

- Frontend: Next.js y React
- Backend: NestJS y Node.js
- Control de versiones: Git y GitHub
- Base de datos propuesta: PostgreSQL

## Estructura del proyecto

- `frontend/`: interfaz de usuario.
- `backend/`: API y lógica del servidor.

## Estado actual

Se cuenta con la estructura inicial del frontend y backend. La integración entre ambos, la conexión a la base de datos y las funciones de inventario están pendientes de desarrollo.
